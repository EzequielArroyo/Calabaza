# Calabaza

Calabaza is a location-first marketplace that helps customers discover and reserve products from nearby local stores.

Customers reserve products online, pick them up in person, and pay directly at the store.

---

# Tech Stack

- Next.js (App Router)
- TypeScript
- PostgreSQL
- Prisma
- Tailwind CSS

---

# Requirements

- Node.js (LTS)
- PostgreSQL

---

# Installation

```bash
npm install
```

---

# Environment Variables

Create a `.env` file.

Example:

```env
DATABASE_URL=
```

---

# Development

Start the development server:

```bash
npm run dev
```
